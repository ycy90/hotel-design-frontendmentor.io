# Hotel booking confirmation — Frontend Practice

> Note: This is a free recreation of the original design. No Figma/source file was provided for this challenge — the layout was reproduced by referencing the challenge images, so some visual details may differ slightly.

A small Frontend Mentor practice project: a hotel booking confirmation page. This repo contains the HTML and CSS for the hotel booking confirmation layout and basic UI.

## What I've done so far

- ✅ Created the page structure: `hotel-design/index.html`.
- ✅ Built primary layout and styles: `hotel-design/styles.css`.
- ✅ Implemented a left navigation with logo, nav links and a notification badge.
- ✅ Implemented a weather card and an address bar in the nav.
- ✅ Implemented the main header area with booking status and greeting (e.g., "Bienvenue, Lucia.").
- ✅ Added two action buttons in the header: "Print receipt" and "Add to Calendar".
- ✅ Completed the hero section with receipt card (rotated) and welcome note card from host.
- ✅ Completed the services section with three cards: Arrival (check-in info), WIFI (credentials with copy button), and Breakfast (timing and details).
- ✅ **Page layout complete** — all main sections are structurally in place and positioned.
- ✅ Added typography using Fraunces, DM Sans, and DM Mono
- ✅ Implemented CSS variables for colors and fonts
- ✅ Improved HTML structure and readability
- ✅ Cleaned up unnecessary CSS rules
- ✅ Added hover effects and transitions
- ✅ Organized components and spacing
- ✅ **Refactored class names for better consistency**
- ✅ **Created shared component selectors** (buttons, icon containers, info boxes, etc.) — partial implementation
- ✅ **Reduced duplicated CSS with common selectors** — partial implementation
- ✅ **Improved semantic HTML** where possible
